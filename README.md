# АИС «Электронная медицинская карта» (ЭМК)

Репозиторий ведется по модели ветвления **Git Flow**.

| Ветка | Назначение |
|---|---|
| `main` | только выпущенные и проверенные версии |
| `develop` | интеграция готовых функций к следующему релизу |
| `feature/*` | разработка отдельной функции, ответвляется от `develop` |
| `release/*` | стабилизация версии перед выпуском (раз в квартал) |
| `hotfix/*` | срочные исправления выпущенной версии, ответвляется от `main` |

Перед слиянием `release/*` в `main` обязательны регрессионное и нагрузочное тестирование и аудит безопасности (см. `docs/SECURITY.md`).
