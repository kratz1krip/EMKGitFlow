# Проверки безопасности релиза

Перед выпуском каждой версии ЭМК выполняются:

1. Статический анализ кода (SAST) в ветке `release/*`.
2. Динамическое тестирование (DAST) на тестовом стенде.
3. Аудит защиты персональных данных пациентов.
4. Проверка, что в журналах нет ФИО, диагнозов и номеров полисов.

Ветка `release/*` сливается в `main` только после успешного прохождения всех пунктов.
